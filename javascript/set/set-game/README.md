# set-game

## About

Browser implementation of the Set card game (81 cards, find triples) as a Vue 3
+Vite web app with Pinia stores. Rules: `INSTRUCTIONS.md`.

- Stack: Vue 3, Pinia, Tailwind, Vite 7
- Entrypoint: `index.html` (`src/`)
- Commands: `npm install`, `npx vite` (dev), `npx vite build`, `npx vite preview`
