# Godot

## About

Godot 4 editor projects (scenes + GDScript/C#). No `dotnet build` flow —
open/import the project folder in the Godot editor (pinned: 4.7.2, see
`%GODOT_BIN%`).

- Stack: Godot 4.x, GDScript
- Entrypoint: per project (e.g. `tower-defense/scenes/Main.tscn`)

## Projects

- [tower-defense](tower-defense/) — Sci-Fi 2D maze tower defense prototype (GDScript)
