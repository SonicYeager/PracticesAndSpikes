# trench-warfare

## About

Concept for a WW1 trench-warfare "creep game" in the spirit of *Warfare 1917*
(ConArtists, 2008) — with a sandbox-first twist: data-driven units, free custom
battles and explicit room for wild unit combos and unusual strategies.
Planned as a Godot 4.7.2 / GDScript project reusing the `tower-defense` tooling
(GUT, placeholder generators, telemetry).

- Stack: Godot 4.7.2, GDScript (planned — no project files yet)
- Status: **concept phase** — vision + design docs only, no code
- Scope: one screen, 5–15 min battles; sandbox/custom first (solo vs. AI, local hotseat planned), campaign only as an optional framework later
- Tone: stylized, respectful at the core
- Inspired by: *Warfare 1917* (mechanics study; no assets, names or sounds reused)
- Working title: *Trench Warfare*; final name TBD
