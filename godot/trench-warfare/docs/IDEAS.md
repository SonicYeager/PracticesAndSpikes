# Ideen-Parkplatz — Trench Warfare (Arbeitstitel)

Geparkte Ideen aus dem Konzept/Workshop (2026-10-02). Kein Scope-Versprechen —
wieder aufgreifen, wenn eine Slice es rechtfertigt (Prüfung gegen P1–P3 in
`docs/VISION.md`).

| Idee | Warum geparkt | Wieder aufgreifen, wenn … |
|---|---|---|
| Einheiten über Fraktionen hinweg mischen | nicht in den Top-Reglern (Workshop) | Pool-Mix als Experiment ausdrücklich gewünscht ist |
| Einheiten-Stats direkt editieren (Labor-Regler) | Komplexität > Nutzen im MVP | gezielte Balance-Sessions anstehen |
| Karten-Editor (Gräben/Hazards setzen) | Regler + Presets reichen zuerst | Sandbox-Nachfrage nach eigenen Karten da ist |
| Größere Karten / Scroll | Ein-Bildschirm-Fokus (5–15 Min pro Gefecht) | Sessions länger werden sollen |
| Online-Teilen/Mehrspieler | Hotseat steht davor | die lokale Version nachweislich Spaß macht |
| Sound-/Art-Pass (eigene Assets statt Platzhalter) | Konzeptphase, kein Code | S01–S03 stehen und der Kern trägt |
